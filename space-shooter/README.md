# Space Shooter

A fast-paced arcade shooter built with Python.

## Features

* Player spaceship
* Enemy waves
* Shooting mechanics
* Score system
* Game Over screen

## Controls

* Arrow Keys / WASD to move
* Spacebar to shoot

## Installation

```bash
python3 main.py
```
