# Snake Game

A classic Snake game built with Python.

## Features

* Snake movement
* Food collection
* Score tracking
* Increasing difficulty
* Game Over detection

## Controls

* ↑ Up Arrow
* ↓ Down Arrow
* ← Left Arrow
* → Right Arrow

## Installation

```bash
python3 main.py
```
