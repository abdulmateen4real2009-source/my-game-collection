# Typing Shooter V2

A typing-based arcade game where words fall from the top of the screen and must be destroyed by typing them correctly.

## Features

* Falling word enemies
* Real-time typing combat
* Instant word destruction
* Combo system
* Lives system
* Progressive difficulty

## Gameplay

Type the falling words before they reach the bottom of the screen.

Correct typing increases your score and combo multiplier.

## Requirements

* Python 3
* Pygame

## Installation

```bash
pip install pygame
python3 main.py
```
