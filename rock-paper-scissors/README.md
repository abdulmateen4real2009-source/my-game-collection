# Rock Paper Scissors

A Python implementation of the classic Rock-Paper-Scissors game.

## Features

* Play against the computer
* Random computer moves
* Win/Lose/Draw detection
* Simple and beginner-friendly code

## How to Play

Choose one of:

* Rock
* Paper
* Scissors

The computer will make its choice and the winner will be determined automatically.

## Installation

```bash
python3 main.py
```
