# Typing Shooter V3 – Cyberpunk Edition

A cyberpunk-themed typing shooter built with Python and Pygame.

## Features

* 🎯 Target Locking System
* 💥 Particle Explosions
* 🏆 High Score Saving
* ⚡ Combo Multiplier
* ❤️ Lives System
* 🌌 Animated Background
* 🚀 Dynamic Difficulty Scaling
* 🎮 Arcade-Style Gameplay

## Gameplay

Words descend from the top of the screen.

Type the correct letters to lock onto a target and destroy it before it reaches the bottom.

Build combos to maximize your score and compete against your personal best.

## Requirements

* Python 3
* Pygame

## Installation

```bash
pip install pygame
python3 main.py
```
